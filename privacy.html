Privacy policy

Personal AI Agent — last updated 22 November 2026

What this app is

Personal AI Agent is a private tool used by one person, its owner, on the owner's own computer. It is not a service for other people.

What Google data it uses

With the owner's permission it reads the owner's own Gmail messages (to find one-time sign-in codes and document notifications) and creates files in the owner's own Google Drive (copies of the owner's own account statements). It may also read the owner's Google Calendar events.

How that data is handled

  • All processing happens on the owner's own computer.
  • Google data is not sent to, stored on, or shared with any other server, company or person.
  • Data is not sold, used for advertising, or used to train any model.
  • The app keeps only what the owner asks it to keep, on the owner's own computer and in the owner's own Google Drive.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
